# AWS S3 Static Website Hosting

## 📌 Project Overview
This project demonstrates hosting a static website using Amazon S3 and Amazon CloudFront.

## 🛠️ AWS Services Used
- Amazon S3
- Amazon CloudFront
- AWS IAM

## 🚀 Features
- Hosted a static HTML website on Amazon S3
- Configured bucket permissions for public access
- Enabled Static Website Hosting
- Distributed content globally using CloudFront

## 📂 Project Files
- index.html

## 📖 Steps Performed
1. Created an S3 bucket
2. Enabled Static Website Hosting
3. Uploaded the website files
4. Configured bucket permissions
5. Created a CloudFront distribution
6. Verified website accessibility
